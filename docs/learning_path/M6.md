## 二、核心概念（先理解再动手）

### 2.1 为什么要备份 SQLite 单文件？

SQLite 是**单文件数据库**（train_record.db 一个文件装所有表），
这是它最大的优势：备份 = 复制一个文件，恢复 = 覆盖一个文件。
不用 mysqldump、不用事务日志——`cp` 一下就是完整备份。

本项目做**网页版备份**（管理员在 `/admin/backup` 页下载/上传），
而不是 ssh 上去手动 cp，因为：
1. 手机/浏览器就能操作，不用登服务器
2. 下载的 `.db` 文件可以直接用 sqlite3 打开查看（排查问题的最后手段）

### 2.2 导出文件下载的本质：HTTP 响应头

浏览器下载文件靠的是 **Content-Disposition 响应头**：

```
Content-Disposition: attachment; filename="train_record_2026-08-15.db"
```

- `attachment` → 浏览器不显示内容，而是弹出"保存文件"对话框
- `filename="..."` → 默认保存的文件名
- 没有这个头 → 浏览器把字节当网页渲染（数据库二进制会变成乱码）

axum 里返回下载的写法：

```rust
// 返回 (头, 字节) 元组，axum 自动组装响应
Ok((
    [(header::CONTENT_DISPOSITION, format!("attachment; filename=\"...\""))],
    bytes,
))
```

### 2.3 导入恢复 = 覆盖文件 + 重启连接池

上传的 `.db` 文件要**覆盖**正在用的数据库。难点：
- SQLite 文件被连接池占用，直接覆盖会损坏
- 安全做法：先关闭连接池 → 覆盖文件 → 重新打开连接池

axum 的 `AppState.pool` 是共享的，handler 里要：
1. `pool.close().await`（等所有连接归还后关闭）
2. `fs::copy(上传文件, 数据库路径)`
3. 用新的数据库路径重新 `SqlitePool::connect` 并**替换** AppState 里的 pool

⚠️ 状态替换：AppState 在 handler 里是 `State(state)` 拿到的引用，
要替换需要 `Arc` 或 `RwLock` 包装。M6 教学上简化处理：
**导入成功后提示"请重启服务生效"**，不热替换连接池
（单用户工具，重启成本低；热替换是 M7 打磨项）。

### 2.4 CSV/JSON 导出给谁用？

- **CSV**：Excel 能直接打开，给"想看表格/做数据分析"的场景
  （你的 Python_pkg 数据分析项目就是吃 CSV 的）
- **JSON**：程序间交换格式，M8 REST API 也会用，先熟悉 serde 序列化

两者都是**只读导出**（不改数据库），纯函数式处理：查数据 → 序列化 → 下载。

### 2.5 PWA 是什么？为什么手机训练场景需要？

**PWA（Progressive Web App）** = 网页 + 两个文件：

1. **manifest.json**：声明应用名、图标、主题色、全屏模式
   → 手机浏览器"添加到主屏幕"后，像 App 一样全屏打开（无地址栏）
2. **Service Worker（SW）**：浏览器后台的 JS，拦截请求、缓存资源
   → 静态资源（CSS/JS）缓存后，断网也能打开已访问过的页面

对训练场景的价值：健身房信号差时，today 页只要访问过一次，
静态资源已缓存，刷新页面不白屏（数据请求仍需要网络——
**完整离线可用需要 SW 缓存数据，M7 打磨再考虑**，M6 先缓存静态资源）。

```html
<link rel="manifest" href="/static/manifest.json">
<script>
    if ('serviceWorker' in navigator) {
        navigator.serviceWorker.register('/static/sw.js');
    }
</script>
```

## 三、M6 要做什么（分步）

### 第 1 步：`src/handlers/backup.rs` —— 备份页 + 下载 + 上传（新建）

文件：`src/handlers/backup.rs` + `handlers/mod.rs` 加 `pub mod backup;`

| 路由 | 方法 | 功能 |
|------|------|------|
| `/admin/backup` | GET | 备份管理页（下载/上传按钮） |
| `/admin/backup/download` | GET | 下载数据库文件（.db） |
| `/admin/backup/upload` | POST | 上传 .db 恢复 |
| `/admin/backup/export?format=csv\|json` | GET | 导出全部训练记录（CSV/JSON） |

要求：
1. 三个 handler 都是**管理员专属**（用户管理同款：handler 内部检查 `user.is_admin`）
2. `backup_download`：
   - 读数据库文件字节：`tokio::fs::read(&state.config.database_path).await`
   - 文件名带日期：`train_record_{date}.db`（date 用 SQLite `date('now','localtime')`）
   - 返回 `(Content-Disposition 头, bytes)` 下载
3. `backup_upload`（Multipart 上传）：
   - 校验扩展名是 `.db`
   - 先备份当前库（改名 `train_record.db.bak-{时间戳}`，和部署时的手动备份同款）
   - 上传文件写入临时文件 → 校验是合法 SQLite（读前 16 字节是
     `SQLite format 3\0`，防上传垃圾文件）
   - `fs::copy` 覆盖数据库 → 提示"请重启服务生效"
   - ⚠️ axum 的 Multipart 提取器要开 feature：`axum = { features = ["multipart"] }`
4. `export_csv_json`：
   - 查当前用户全部记录（JOIN exercises 拿动作名）：
     `SELECT r.*, e.name FROM records r JOIN exercises e ON r.exercise_id = e.id
      WHERE e.user_id = ? ORDER BY r.record_date, r.id`
   - CSV：手工拼（列名行 + 数据行，字段含逗号要加引号转义——
     教学版简化：字段值有逗号/换行时用双引号包裹，内部 `"` 翻倍）
   - JSON：`serde_json::to_string(&rows)`（rows 用 `serde_json::json!` 构造）
   - 同样返回下载头（`Content-Type: text/csv` / `application/json`）

### 第 2 步：`static/manifest.json` —— PWA 清单（新建）

```json
{
    "name": "训练记录",
    "short_name": "训练",
    "start_url": "/today",
    "display": "standalone",
    "background_color": "#ffffff",
    "theme_color": "#2196f3"
}
```

- `display: standalone` → 全屏无地址栏（像 App）
- `start_url` → 从主屏幕打开时进 today 页（训练场景直达）
- 图标可选（M7 加，教学版先不加 icon）

### 第 3 步：`static/sw.js` —— Service Worker（新建）

```js
// 静态资源缓存：访问过的页面离线可用
const CACHE = 'train-record-v1';
self.addEventListener('install', (e) => {
    e.waitUntil(caches.open(CACHE));
});
self.addEventListener('fetch', (e) => {
    // 只缓存 GET 静态资源，跳过 /api 和 POST
    if (e.request.method !== 'GET') return;
    e.respondWith(
        caches.match(e.request).then((hit) =>
            hit || fetch(e.request).then((resp) => {
                const copy = resp.clone();
                caches.open(CACHE).then((c) => c.put(e.request, copy));
                return resp;
            })
        )
    );
});
```

**第 1 题**：SQLite 是**单文件**数据库，所有表都在**一个 .db 文件**里，
备份 = **复制这个文件**，恢复 = **覆盖这个文件**。

**第 2 题**：**Content-Disposition** 响应头，`attachment` 表示**弹出保存对话框**
（不渲染内容），`filename="..."` 表示**默认保存文件名**。
没有这个头浏览器会**把内容当网页渲染**（二进制变乱码）。

**第 3 题**：数据库文件被**连接池**占用，直接覆盖会**损坏数据库**；
热替换需要把 AppState 的 pool 包进**Arc 或 RwLock**（M7 打磨项）。

**第 4 题**：manifest.json 管**应用外观**（主屏幕图标/全屏/启动页），
Service Worker 管**离线缓存**（拦截请求缓存静态资源，离线可用）。

**第 5 题**：CSV 给**人**（Excel 直接打开），JSON 给**程序**（交换格式）。
两者都是**只读**（不改数据库）。
