# 训练记录系统 · 项目提案

## 背景

`Python_pkg/` 下有一个用 Python 编写的健身训练记录程序，其工作流程为：

1. 在 OneNote 上规划每天的训练计划
2. 训练时使用 OneNote 查看计划并记录
3. 回家后将 OneNote 上的训练记录表格复制粘贴到 `Python_pkg/table.xlsx`
4. 由 pandas 读取 xlsx 并归档至 `Python_pkg/all_data`

### 现有方案的缺陷

1. **OneNote 配合不便**：计划与记录分散在笔记软件中，流程割裂、无结构
2. **pandas 存在行数限制**：长期使用后会出现记录断层
3. **无法即时归档**：训练完成后需回家手动复制到 Excel 再导入，过程繁琐

## 项目目标

1. **使用 Rust 重写**整个项目
2. **改用数据库**保存训练数据，替代 CSV
3. **部署在 Linux 服务器**上
4. **支持手机和电脑浏览器访问**，实现：
   - 训练前制定当日计划
   - 训练时查看当日计划、记录感受、制定某动作的后续安排
   - **即时归档**（替代原"回家复制到 Excel 再归档"的流程）
